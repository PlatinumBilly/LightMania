## 2.实现基本的bpm与时间线的对齐
### **2.0**基本概念
1. bpm（beat per minute）每分钟节拍数，用于衡量一首曲子的快慢
2. beat 即节拍，是一首音乐的基本单位
3. 相对时间，由`节拍+精分细度+小节序号(bar)`构成。如 
```C
    {Beat: 120, Division:4，Bar:3}
```

### **2.1**基本目标
- [ ] 给定初始的bpm和精分细度（Division） 将相对时间与绝对时间进行互相转化

#### **2.3**基础公式

##### 相对时间转化为绝对时间


> 相对时间  = beat = (t - offset) × BPM / 60000


---

##### 绝对时间转化为相对时间

> 绝对时间 = offset + beat × (60000 / BPM)
